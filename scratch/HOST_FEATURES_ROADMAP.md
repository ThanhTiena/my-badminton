## 🛠️ Technical Architecture

### New Database Collections
```typescript
venues                      // Venue management
pricing_rules              // Dynamic pricing config
session_polls              // Attendance polls
poll_responses             // Player RSVPs
membership_tier_configs    // Tier definitions
payment_reminder_configs   // Reminder schedules
payment_reminder_logs      // Reminder tracking
notifications              // Notification history
payment_disputes           // Dispute management
court_bookings             // Court calendar (Sprint 5)
shuttlecock_inventory      // Inventory tracking (Sprint 5)
```

### API Endpoints Added
```
# Venue Management
GET/POST    /api/venues
GET/PATCH   /api/venues/:id
GET         /api/analytics/venues

# Pricing Rules
GET/POST    /api/pricing-rules
POST        /api/pricing-rules/calculate

# Polling System
GET/POST    /api/polls
GET/PATCH   /api/polls/:id
GET/POST    /api/polls/:id/responses

# Membership
GET/PATCH   /api/membership-tiers
GET/PATCH   /api/players/:id/membership

# Payment Automation
GET/PATCH   /api/payment-reminders/config
POST        /api/payment/bulk-mark-paid
GET         /api/payment-reminders/log

# Notifications
GET         /api/notifications
PATCH       /api/notifications/:id/read

# Cron Jobs
POST        /api/cron/send-payment-reminders
POST        /api/cron/poll-reminders
POST        /api/cron/update-participation-stats
POST        /api/cron/auto-archive-inactive
```

## 🔒 Security & Privacy Considerations

### Data Protection
- [ ] Player payment data encrypted at rest
- [ ] Email addresses stored securely (not in logs)
- [ ] Payment method details masked (last 4 digits only)
- [ ] Medical notes admin-only access
- [ ] Audit trail for all payment adjustments

### GDPR/Privacy Compliance
- [ ] Player consent for email notifications
- [ ] Opt-out mechanism for reminders
- [ ] Data export capability (player requests own data)
- [ ] Right to be forgotten (archive with anonymization)

### Rate Limiting
- [ ] Email sending rate limited (max 100/hour)
- [ ] API endpoints throttled (prevent abuse)
- [ ] Cron jobs with failure handling
